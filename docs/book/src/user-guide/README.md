# User Guide

This part of the book is about *using* ONTrack. It covers:

- **[Installation](installation.md)** — building the desktop app from source, the Nix development shells, configuring API keys, and building the Android app (APK/AAB).
- **[Controls](controls.md)** — every button, field, and tab in the desktop and mobile apps, and exactly what each one does.
- **[Settings](settings.md)** — every configuration option the apps expose, what the defaults are, and where they are stored.
- **[Everyday Use](everyday-use.md)** — the real workflows: adding stops, picking a distance backend, running the optimizer, and getting the route out to your maps app.
