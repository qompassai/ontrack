# Code

This part of the book is for developers. It covers:

- **[Architecture](architecture.md)** — how the workspace is organized, the data pipeline both apps share, and the threading model that keeps the UIs responsive.
- **[Crate Tour](crate-tour.md)** — a module-by-module walk through `ontrack-core`, `ontrack-desktop`, and `ontrack-mobile`, including the Slint interface contract.

The workspace root is `Cargo.toml` (resolver v2, three members), version `2.0.0`, edition 2021, Apache-2.0.
